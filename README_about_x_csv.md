# メッシュCSVファイルについて

メッシュファイル（`.x`）と同じディレクトリに、同じ名前の `.csv` ファイルを置くことで、メッシュの描画設定を指定できます。

例：`aaa.x` に対して `aaa.csv` を用意する。

CSVファイルが存在しない場合はエラーにはならず、デフォルトの設定で描画されます。

---

## フォーマット

各行に `キー,値` の形式で記述します。

```
MeshType,POM
smooth,y
```

---

## パラメータ一覧

### MeshType

メッシュの描画タイプを指定します。

| 値 | 説明 |
|---|---|
| `POM` | Parallax Occlusion Mapping を使用する |
| `NormalMapping` | Normal Mapping を使用する |
| `EnvMapping` | 環境マッピング（キューブマッピング）を使用する |
| `None` | 特殊な描画なし（デフォルト） |

---

### smooth

法線を滑らかに補間するかどうかを指定します。

| 値 | 説明 |
|---|---|
| `y` | スムージングを有効にする |
| `n` | スムージングを無効にする |

---

### sss

サブサーフェイススキャッタリングを有効にするかどうかを指定します。

| 値 | 説明 |
|---|---|
| `y` | SSSを有効にする |
| `n` | SSSを無効にする |

### sssIntensity

SSSの強さを指定します。

```
sssIntensity,1.0
```

### sssColor

SSSで透けて見える色をR,G,Bで指定します（各値は0〜255）。

```
sssColor,0,255,127
```

---

### sway

草などを風でそよがせる揺れエフェクトを有効にするかどうかを指定します。

| 値 | 説明 |
|---|---|
| `y` | 揺れを有効にする |
| `n` | 揺れを無効にする |

### swayIntensity

揺れの強さを指定します。

```
swayIntensity,1.0
```

---

### wave

海面のような波エフェクトを有効にするかどうかを指定します。

| 値 | 説明 |
|---|---|
| `y` | 波を有効にする |
| `n` | 波を無効にする |

### waveIntensity

波の強さを指定します。

```
waveIntensity,1.0
```

---

### litByPointLight

ポイントライトによる照明を受けるかどうかを指定します。

| 値 | 説明 |
|---|---|
| `y` | ポイントライトの影響を受ける |
| `n` | ポイントライトの影響を受けない |

---

### collision

衝突判定の対象とするかどうかを指定します。

| 値 | 説明 |
|---|---|
| `y` | 衝突判定を有効にする |
| `n` | 衝突判定を無効にする |

---

## 記述例

```
MeshType,NormalMapping
smooth,y
sss,y
sssIntensity,1.0
sssColor,0,255,127
sway,y
swayIntensity,1.0
wave,n
waveIntensity,1.0
litByPointLight,y
collision,y
```
