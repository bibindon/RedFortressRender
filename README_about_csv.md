# CSVファイルについて

メッシュファイル（`.x`）と同じディレクトリに、同じ名前の `.csv` ファイルを置くことで、メッシュの描画設定を指定できます。

例：`aaa.x` に対して `aaa.csv` を用意する。

CSVファイルが存在しない場合はエラーにはならず、デフォルトの設定で描画されます。

---

## フォーマット

各行に `キー,値` の形式で記述します。

```
MeshType,POM
smooth,y
```

---

## パラメータ一覧

### MeshType

メッシュの描画タイプを指定します。

| 値 | 説明 |
|---|---|
| `POM` | Parallax Occlusion Mapping を使用する |
| `NormalMapping` | Normal Mapping を使用する |
| `None` | 特殊な描画なし（デフォルト） |

### smooth

法線を滑らかに補間するかどうかを指定します。

| 値 | 説明 |
|---|---|
| `y` | スムージングを有効にする |
| `n` | スムージングを無効にする |

記述しない場合は、プログラム側のデフォルト設定が使用されます。

### envmapping

環境マッピング（キューブマッピング）を行うかどうかを指定します。

| 値 | 説明 |
|---|---|
| `y` | 環境マッピングを有効にする |
| `n` | 環境マッピングを無効にする |

記述しない場合は、プログラム側のデフォルト設定が使用されます。

---

## 記述例

```
MeshType,POM
smooth,y
```

```
MeshType,NormalMapping
smooth,n
envmapping,y
```
