# RedfortressRender

DirectX 9 ベースの自作 3D 描画ライブラリと、その動作確認用サンプルをまとめたプロジェクトです。  
メッシュ描画、アニメーション、各種ポストエフェクト、法線マッピング系の表現を試しながら、レンダリング機能を少しずつ追加していくための実験場として作られています。

## 主な内容

- `Render`
  描画ライブラリ本体です。カメラ、ライト、メッシュ描画、スプライト、フォント、GBuffer、SSAO、深度バッファシャドウ、ガウシアンブラー、ブルーム、スターバースト、フォグなどの処理を含みます。

- `Sample`
  ライブラリの確認用サンプルです。  
  各種モデルやテクスチャを読み込み、設定ダイアログからポストエフェクトや描画パラメータを切り替えて挙動を確認できます。

- `GrassLandSample`
  別サンプル用のプロジェクトです。

- `UnitTest1`
  単体テスト用のプロジェクトです。

## このプロジェクトで試している表現

- 通常メッシュ描画
- アニメーションメッシュ描画
- スキンメッシュ描画
- インスタンシング
- 深度バッファシャドウ
- SSAO
- ガウシアンフィルタ
- ブルーム
- スターバースト
- フォグ
- 彩度フィルタ
- 法線マッピング
- 視差遮蔽マッピング
- サブサーフェイススキャッタリング

## 開発環境

- Windows
- DirectX 9
- Visual Studio 2026

ソリューションファイルは [Render.sln](/C:/Users/bibindon/source/repos/bibindon/RedfortressRender/Render.sln) です。

## 使い方

まず `Render.sln` を Visual Studio で開いてビルドしてください。  
動作確認は主に `Sample` プロジェクトから行えます。

`Sample` では、設定ダイアログや `RenderSettings.csv` を使って、ポストエフェクトの ON/OFF や各種パラメータを調整できます。  
モデル読み込みや描画結果の確認をしながら、レンダリング機能を段階的に試せるようになっています。

## 補足

このリポジトリは、完成済みの製品コードというより、描画機能の研究・検証・改善を継続するためのワークスペースです。  
そのため、ライブラリ本体とサンプルコードが密接に連動しており、新しい表現を試すためのコードや検証用アセットも含まれています。
